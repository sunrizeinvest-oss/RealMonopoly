## How to actually build this tonight

### Tool choice
- **Fastest:** Google Slides (free, share via link, easy to edit)
- **Cleanest:** Keynote (Mac only, looks polished out of the box)
- **Most editable:** Figma Slides (if you're already comfortable in Figma)

**Recommendation:** Google Slides. Send Corey a "View" link in the email + attach the PDF export.

### 30-minute deck-build process

1. **Open Google Slides** → Create blank presentation → Theme: pick "Modern" or "Simple Dark"
2. **Set aspect ratio** to 16:9 (`File → Page setup → Widescreen 16:9`)
3. **Slide 1**: title slide. Type the headline + your name + the URL.
4. **For slides 2-12**: paste each slide's title + body from this doc. Don't try to make it pretty yet.
5. **Once all content is in:** go back and add ONE visual per slide:
   - Slides 1, 3, 4, 5 → live screenshots from `www.realdealestate.app`
   - Slides 2, 7, 8, 11 → just use the tables / matrices (text is enough)
   - Slides 6, 10 → optional bar/funnel chart (or skip — text is enough)
   - Slide 9 → the 3-column status table (just text)
6. **Brand colors**: Use deep navy `#0a1128` background + brushed brass `#d4af37` accents + soft white `#f0f0f0` text for body. Matches the live site.
7. **Export to PDF**: `File → Download → PDF Document`
8. **Save as**: `RizeAI_Deck_v1.pdf`

### Time budget
- Content paste: 10 min
- Screenshots: 10 min
- Visual polish: 10 min
- Total: **~30 min**
